# Changelog

## 1.0.0 — public-source preparation (2026-10-07)

Existing application and launch materials; this is not an announcement of a published binary release.

- Folder matching, single-image search and multi-folder exact/near-identical grouping.
- Comparison inspector with metadata and synchronized x2/x4 loupe.
- Selection/copy and CSV/HTML reports.
- Incremental SQLite indexing, cached thumbnails, progress/cancellation and logs.
- Immediate Light/Dark and EN/RO switching; JSON translation catalogs.
- Per-user offline setup, root launcher and self-contained x64 layout.
- Donation/About dialogs and aligned visual design.
- English documentation, download-site source and actual-engine captures.

See [release readiness](docs/RELEASE_READINESS.md) for limitations and outstanding gates.
